# Netflix Python SQL Analysis

## Project Overview
This project analyzes the Netflix Titles dataset using Python and Pandas. It performs data cleaning, exploratory data analysis (EDA), and visualizations to understand trends in Netflix content.

## Dataset
- File: netflix_titles.csv
- Source: Netflix Titles Dataset

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code

## Analysis Performed
1. Dataset Information
2. Missing Values Analysis
3. Movies vs TV Shows
4. Top Countries Producing Content
5. Release Year Distribution
6. Top Content Ratings
7. Content Added by Year
